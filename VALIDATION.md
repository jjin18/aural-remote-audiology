# Validation

- Browser checked at 320, 390, 768, 1024, 1440 px: document width equals viewport width at all five sizes.
- Visually reviewed opening, desktop clinic section, mobile clinic section, and mobile enquiry dialog.
- Enquiry: labelled fields, local text download, success status, Escape close and focus return verified.

- JavaScript syntax check passed.
