# Aural — remote diagnostic audiology

Buildless, dependency-free frontend. Serve `dist/` with any static HTTP server. Relative asset paths support GitHub Pages project hosting.

The site uses a restrained pearl-and-graphite visual system, editorial typography, paired striped signal fields, an anchored conceptual audiogram, word reveals and light-sweep buttons. Native scrolling drives the narrative. Motion follows the operating-system preference by default; the footer control overrides it for the current visit.

The Aural name is a proposed identity. All session UI and plotted values are conceptual. No clinical claims, customers, approvals, or patient information are represented. The enquiry interaction downloads a local brief; it does not send or retain enquiry information.

Deployment: publish the contents of `dist/` to a `gh-pages` branch, or upload the GitHub Pages zip. Sites hosting configuration is in `.openai/hosting.json`.

See `VALIDATION.md` for current browser checks and limitations.
